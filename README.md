# Laura Jaramillo · Portafolio

Estratega digital y Marketing Project Manager. Sitio estático (HTML, CSS y JS sin dependencias), animado y adaptado a celular.

- `index.html`: el sitio completo (portada, trabajo, qué hago, cómo pienso, sobre mí y contacto).
- `hd/`: publicaciones y fotos en alta calidad de las cuentas y sitios de las marcas.
- `img/`: capturas de sitios web y casos.
- `cv-*.pdf`: hoja de vida en español e inglés.

Desplegado en Vercel: cada push a `main` publica https://laura-jaramillo.vercel.app
